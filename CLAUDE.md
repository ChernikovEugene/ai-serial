# Инструкции для Claude

- В начале каждой сессии прочитай `docs/HISTORY.md`: там история проекта и место, где остановились.
- После заметной работы (новая функция, важное решение, смена планов) добавь в конец `docs/HISTORY.md`
  запись с датой: что сделано, что не доделано, следующие шаги. Коммить её вместе с изменениями.
- Владелец проекта пишет по-русски, отвечай по-русски.

## Совместная работа

Над репозиторием работают несколько человек, поэтому:

- Каждый работает в своей ветке (например, `eugene/название-задачи`, `friend/название-задачи`). В `main` напрямую не пушим.
- Изменения попадают в `main` только через pull request, который смотрит второй участник.
- Каждый pull request добавляет запись с датой в `docs/HISTORY.md`: кто, что сделал, что осталось.
- Перед началом работы обнови `main` (`git pull`) и создай ветку от него.
