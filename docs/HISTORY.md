# История проекта ai-serial

Журнал работы над проектом. Новые записи добавляются в конец, с датой.
Задача файла: чтобы с любого компьютера (дома, на ноутбуке, в облачной сессии) можно было быстро вспомнить, где остановились.

## Что это за проект

«Студия сериала для TikTok»: локальное веб-приложение для производства вертикального сериала.
Сценарий серии → шоты под Veo 3 → генерация видео → просмотр и правки → очередь и календарь постинга.

- Стек: FastAPI + SQLite + чистый JS (без фреймворков), Python 3.10+.
- Запуск: двойной клик по `start.bat` (Windows), приложение на http://127.0.0.1:8765.
- Данные: папка `data/` (база, картинки, видео), в git не попадает.
- Изначально проект лежал в `E:\Projects\moviestudio` на домашнем компьютере.

   - Плеер 9:16, комментарии с таймкодом.
   - Очередь и календарь: одна серия в день, закрепление даты, бэклог, «убрать пропуски».
   - Статусы серии от «В разработке» до «Опубликовано».
3. `Roles, voice types, completeness gate and re-generation`:
   - роли: продюсер (админ), сценарист, монтажёр, зритель; права проверяются в API;
   - реплики «в кадре» и «за кадром» (`МАША (за кадром): …`, `(з/к)`);
   - сценарий нельзя согласовать, пока в шотах есть пробелы (продюсер может принудительно);
   - монтажёр может улучшить промпт и перегенерировать один шот, дубль хранит промпт и причину;
   - смоук-тест `tests/smoke_roles.py`.

Пример серии: `examples/серия_1_пример.txt` («Месть за видео»).

## 2026-10-07: кнопка «Правка» и запуск на Mac (aristerri)

- Кнопка «Правка» справа внизу: текст + скриншоты → GitHub Issue с меткой `правка` (скриншоты в ветке `pravki-shots`).
  Вкладка «Все правки»: статус (ждёт / в работе / сделано / снята), обсуждение с ответами, «Снять».
  Код: `app/feedback.py`, `app/github.py`, `app/static/js/feedback.js`, адреса `/api/feedback*`.
- В `CLAUDE.md` раздел «Правки с сайта»: по команде «Запусти правки» Claude берёт открытые задачи, ставит метку
  «в работе», вносит через PR с `Closes #N`, вопросы задаёт комментарием в задаче.
- Доступ к GitHub: `gh auth token`, иначе новая настройка `github_token`, иначе переменная `GITHUB_TOKEN`.
- `start.command`: запуск на macOS через `uv` (Python 3.12 из Homebrew на macOS 26 сломан: не грузится `pyexpat`).

### Что не проверено

- Отправка настоящей правки (создание задачи и загрузка скриншота на GitHub): проверены окно, вставка скриншота
  и чтение списка правок с GitHub.

### Важно

Репозиторий публичный: правки и скриншоты в Issues видны всем. Если это не подходит, репозиторий нужно сделать приватным.
