# Сайт ↔ Пульт фермы: генерация видео по шотам (MiniMax H3)

Документ для разработчика (агента) сайта. Пользователь нажимает на сайте «Отправить генерацию» — студийная
рендер-ферма забирает шоты, делает видео на модели MiniMax H3 (видео со звуком и синхроном губ), доводит его до 1080p
и возвращает на сайт готовым роликом, по ходу сообщая статус и проценты.

**Главное: сайт никуда не обращается сам.** Ферма стоит в студии за сетью, в которую нельзя зайти снаружи, поэтому
всё делает Пульт фермы: сам заходит на сайт за новыми шотами, сам отправляет на сайт статус и сам загружает видео.
Сайту нужно сделать **три точки приёма** (§2–§4) и хранить шоты со статусами.

Всё ниже проверено на ферме 16–20.10.2026.

## 0. Как это выглядит

1. Пользователь нажимает «Отправить генерацию» → сайт помечает шоты сцены статусом «ждёт фермы».
2. Пульт раз в 10 секунд спрашивает `GET /api/farmhub/jobs/pending` и забирает новые шоты (и их картинки по ссылкам).
   По каждому сразу приходит `job.accepted` (принят) или `job.rejected` (не может быть сделан — с причиной).
3. Пока ферма работает, приходят события на `POST /api/farmhub/jobs/{id}/status`: старт, проценты, этап.
4. После генерации Пульт загружает **черновик** (`POST /api/farmhub/jobs/{id}/files`, `kind=draft`) и шлёт `job.stage`.
5. После доводки до 1080p загружает **финальный ролик** (`kind=final`) и шлёт `job.finished`.

Если ферма выключена или в студии нет интернета, шоты спокойно ждут на сайте и будут забраны, когда ферма вернётся.
Если на время не работает сайт, Пульт догрузит видео и повторит события, когда сайт снова ответит (до суток).

## 1. Защита

- Одна общая строка-секрет: `FARMHUB_SECRET` (начинается с `whsec_`). Её даёт владелец Пульта; храните в настройках
  сервера, не в коде и не в браузере.
- Каждый запрос Пульта к сайту идёт с заголовком `Authorization: Bearer <FARMHUB_SECRET>`.
  Запросы без него или с другим значением — **401**. Сравнение — постоянного времени (`crypto.timingSafeEqual` /
  `hmac.compare_digest`).
- Адрес точек по умолчанию: `https://pari-altushka.ru/api/farmhub/...`. Если у вас другой путь, сообщите владельцу
  Пульта — это одна настройка на его стороне.
- Сайт должен открываться по https из интернета (Пульт ходит на него из студии).

## 2. Точка 1 — шоты, ждущие ферму

```
GET /api/farmhub/jobs/pending
→ 200 {"shots": [ <шот>, <шот>, ... ]}
```

- Отдавайте шоты со статусом «ждёт фермы», в нужном порядке (что раньше — тем раньше), не больше 50 за раз.
- Шот отдаётся, пока по нему не пришло `job.accepted` или `job.rejected` (после этого — не отдавать).
  Если отдадите ещё раз, Пульт повторно его не возьмёт: он помнит `id`.
- Для повторной генерации того же шота создайте новый `id` (например, `shot-17-take2`).

### Шот

```json
{
  "id": "scene12-shot1",
  "batch": "scene12",
  "character": "https://pari-altushka.ru/media/chars/asya-look.png",
  "face": "https://pari-altushka.ru/media/chars/asya-face.png",
  "location": "https://pari-altushka.ru/media/locations/asya-room.png",
  "line": "Сегодня первый раз играю в Доту без Олега",
  "voice": "normal calm voice",
  "action": "she sits at her computer with her headphones and looks into the camera"
}
```

| Поле | Обязательно | Язык | Что это |
|---|---|---|---|
| `id` | **да** | — | ваш уникальный id шота (до 200 символов); по нему придут статус и файлы |
| `batch` | нет | — | id сцены / пачки — для вашего удобства, вернётся в событиях |
| `character` | да, или `face` | — | **ссылка** на картинку: персонаж в нужном образе (одежда, причёска; лучше в похожей обстановке) |
| `face` | да, или `character` | — | **ссылка**: лицо персонажа крупно, анфас |
| `location` | нет | — | **ссылка**: место действия |
| `location_text` | нет | **англ.** | место словами, если нет картинки `location` |
| `action` | **да** | **англ.** | что происходит в кадре: `she sits at her computer with her headphones and looks into the camera` |
| `line` | нет | **рус.** | реплика, одна, одного персонажа. Пусто — шот без речи |
| `voice` | нет | **англ.** | как говорит: `normal calm voice`, `excited fast voice`, `whisper` (по умолчанию `normal calm voice`) |
| `shot_size` | нет | **англ.** | крупность: `medium shot` (по умолчанию), `close-up`, `wide shot` |
| `camera` | нет | **англ.** | камера; по умолчанию `static camera, locked-off, no camera movement` |
| `style` | нет | **англ.** | стиль; по умолчанию `Cinematic vertical TikTok series, realistic, natural lighting, shallow depth of field` |
| `sound` | нет | **англ.** | звук шота без реплики; по умолчанию `quiet room ambience, no music` |
| `aspect` | нет | — | `9:16` (по умолчанию), `16:9`, `1:1`, `3:4`, `4:3` |
| `seconds` | нет | — | 1–10; по умолчанию по длине реплики (8 слов → 4 с), без реплики — 5. Лучше не задавать |
| `quality` | нет | — | `final` (по умолчанию: полное качество + доводка до 1080p) или `draft` (быстрый мыльный черновик, без доводки) |
| `finish` | нет | — | доводка до 1080p; по умолчанию `true` для `final`, `false` для `draft` |
| `seed` | нет | — | число: тот же seed и те же поля → тот же дубль; пусто — каждый раз новый дубль |
| `priority` | нет | — | 0–100, по умолчанию 50; больше — раньше |

**Картинки:** png / jpg / webp до 50 МБ. Пульт скачивает их по ссылкам. Ссылки на вашем домене он запрашивает
с заголовком `Authorization: Bearer <FARMHUB_SECRET>` (так можно отдавать закрытые файлы только ему); на чужие домены
секрет не отправляется — там ссылки должны быть открытыми. Одну и ту же ссылку (персонаж сцены) Пульт скачивает один раз
в час. Если картинка временно недоступна (сбой сети, 5xx), Пульт попробует на следующем опросе; если 404 — отклонит шот.

### Правила, без которых получается брак

- **Всё, кроме `line`, — по-английски.** Русский текст вне реплики модель читает вслух; такой шот Пульт отклонит
  (`job.rejected` с названием поля). Если сценарий пишется по-русски, переводите описания перед отправкой.
- Имена персонажей не пишите в `action` (модель может их произнести) — персонаж задаётся картинками.
- **Одна реплика одного персонажа на шот.** Диалог — несколько шотов.
- **Картинки:** без подписей, рамок, скруглённых углов и коллажей (модель переносит их в видео). Лист персонажа
  с ракурсами разрежьте на отдельные картинки. Лучшая связка: `character` — образ, `face` — лицо, `location` — место.
- Если место берётся не из `location`, а из фона `character`, дайте `character` на нейтральном фоне.

Промпт для модели Пульт пишет сам по этим полям; готовый текст приходит в событиях: `job.params.prompt`.

## 3. Точка 2 — статус шота

```
POST /api/farmhub/jobs/{id}/status          Content-Type: application/json
{"event": "job.progress", "job": { ... }}
→ отвечайте 200 сразу, обрабатывайте после
```

| `event` | Когда | Что показать |
|---|---|---|
| `job.accepted` | Пульт взял шот в очередь | «Принято фермой», место в очереди `position` |
| `job.rejected` | шот нельзя сделать | «Отклонено: {error}» — исправить шот и отправить с новым `id` |
| `job.started` | видеокарта начала генерацию | «Генерация» |
| `job.progress` | прогресс вырос (на 10 %, или на 1 % спустя 30 с) | обновить полосу |
| `job.requeued` | карту забрал рендер студии / ПК уснул / не хватило памяти | «Ждёт видеокарту», прогресс этапа — с нуля |
| `job.stage` | генерация готова, **черновик уже загружен** (§4), идёт доводка | «Доводка до 1080p», показать черновик |
| `job.finished` | конец: `status` = `done` / `failed` / `canceled`; при `done` **финал уже загружен** | «Готово» + плеер |

Тело (`job`):
```json
{
  "id": "71c098a6ebd84bba",
  "ref": "scene12-shot1",
  "batch": "scene12",
  "status": "running",
  "stage": "finish",
  "finish": true,
  "progress": 0.5,
  "position": 0,
  "message": "Farm-05 GPU1 (3090)",
  "outputs": [],
  "raw_outputs": [{"name": "h3-r2v_00003_.mp4", "kind": "video", "size": 4421337}],
  "error": null,
  "updated": 1792822119.9,
  "params": {"prompt": "...", "seconds": 4, "aspect": "9:16 (Portrait Widescreen)", "...": "..."}
}
```

| Поле | Значение |
|---|---|
| `ref` | ваш `id` шота |
| `id` | номер задания в Пульте (для разговора с владельцем Пульта) |
| `status` | `queued` (ждёт карту) · `running` (генерация или доводка) · `done` · `failed` · `canceled` |
| `stage` | `generate` · `finish` |
| `progress` | 0…1 по всему шоту: генерация 0–0,5, доводка 0,5–1 (без доводки — генерация 0–1) |
| `position` | место в очереди; 0 — уже считается |
| `outputs` / `raw_outputs` | какие файлы приходят на точку 3 (финал / черновик): имя, тип, размер |
| `error` | причина `failed` / `rejected`. При `done` с `error` — доводка или загрузка не удались (см. §4) |
| `updated` | время изменения (Unix, секунды) — для порядка |
| `message` | для людей: какая карта, почему вернулся в очередь |

- **События одного шота приходят по порядку, но могут повториться.** Храните `updated` последнего применённого события
  и пропускайте события с `updated` меньше или равным. Исключение — повтор `job.stage` / `job.finished` после догрузки
  файла (§4): он приходит с тем же или бóльшим `updated` и без ошибки загрузки — применяйте его, если у шота сейчас
  стоит ошибка загрузки.
- Отвечайте 2xx быстро (Пульт ждёт до 15 с). На 5xx или таймаут Пульт повторяет: `job.accepted`, `job.stage`,
  `job.finished` — до 5 раз в течение ~4 минут, остальные — один раз. На 4xx не повторяет.

## 4. Точка 3 — приём видео

```
POST /api/farmhub/jobs/{id}/files          Content-Type: multipart/form-data
  kind   = draft | final
  name   = h3-r2v_00003_-1080p.mp4
  job_id = 71c098a6ebd84bba
  file   = <видео mp4>
→ 200 (тело любое, например {"url": "/media/..."})
```

- `draft` — черновик после генерации (≈736×1280, со звуком), приходит **перед** `job.stage`.
- `final` — готовый ролик (≈1080×1880 для 9:16, H.264, звук AAC 48 кГц, громкость −14 LUFS), приходит **перед**
  `job.finished` со `status: "done"`. Без доводки (`draft`-качество) финалом считается сам результат генерации.
- Размер — обычно 3–20 МБ. **Разрешите загрузку до 200 МБ:** во многих хостингах по умолчанию 1–2 МБ
  (nginx `client_max_body_size 200m;`, PHP `upload_max_filesize` и `post_max_size`, лимиты body-parser / multer в Node).
- Сохраните файл в своё хранилище и привяжите к шоту. Повторная загрузка того же `kind` — замена файла.
- Если загрузка не удалась (сайт не ответил, 5xx), событие всё равно придёт, с `error`: «видео … не загрузилось на сайт».
  Пульт будет догружать файл раз в 5 минут в течение суток; когда получится — повторит то же событие уже без ошибки.
  На ответ 4xx (например, 413 — слишком большой файл) не догружает: исправьте лимит.

## 5. Как показывать статус на сайте

Храните у шота: `status`, `stage`, `progress`, `position`, `message`, `error`, `updated`, `farm_job_id`,
`draft_url`, `final_url`.

| Состояние | Условие | Подпись | Полоса |
|---|---|---|---|
| Ждёт фермы | шот отправлен, событий ещё нет | «Отправлено, ждём ферму» | 0 % |
| В очереди | `job.accepted`, `status = queued` | «В очереди фермы: №{position}» | 0 % |
| Генерация | `status = running`, `stage = generate` | «Генерация видео — {progress}%» | 0–50 % |
| Ждёт карту | после `job.requeued` | «Видеокарта занята рендером, ждём» | прогресс этапа сброшен |
| Доводка, в очереди | `stage = finish`, `position > 0` | «Черновик готов, ждёт доводки» | 50 % |
| Доводка | `stage = finish`, `position = 0` | «Доводка до 1080p — {progress}%» | 50–100 % |
| Готово | `status = done`, без `error` | «Готово» + плеер финала | 100 % |
| Готово с замечанием | `status = done`, есть `error` | «Готово, но: {error}» + плеер того, что пришло | 100 % |
| Отклонено | `job.rejected` | «Отклонено: {error}» + «Исправить и отправить» | — |
| Ошибка | `status = failed` | «Ошибка: {error}» + «Повторить» | — |

- Полосу удобно рисовать из двух частей: «Генерация» (0–50 %) и «Доводка» (50–100 %). Процент = `round(progress*100)`.
- Процент считается по шагам модели: может прыгать и стоять по несколько минут (особенно около 90 % в конце доводки).
  Показывайте «идёт…» и время с начала этапа, а не обратный отсчёт.
- После `job.stage` сразу дайте посмотреть черновик — он уже со звуком.
- Если шот «Отправлено, ждём ферму» дольше 2–3 минут — ферма выключена или нет связи; это не ошибка, шот подождёт.

## 6. Время и очередь

- Ферма: 11 видеокарт на 6 ПК. MiniMax H3 одновременно — **6 шотов** (по одному на ПК); вторые карты в это время
  делают доводку других шотов. 11 шотов принимаются сразу, лишние ждут в очереди.
- Шот 4–6 с, `final`: генерация ≈ 11 мин (RTX 4090) / ≈ 24 мин (RTX 3090), доводка ≈ 21 / 38 мин.
  Первый запуск модели на карте дольше на 3–5 мин. Ориентир: 11 шотов с доводкой — 1,5–2 часа.
- `draft`: 2–8 минут на шот, без доводки.
- У рендера Blender в студии приоритет: если он забирает карту, шот возвращается в очередь (`job.requeued`) и начнётся
  заново. До 5 попыток, потом `failed`.
- Отменить шот с сайта в этой версии нельзя (отмена — в Пульте у владельца фермы).

## 7. Что сделать на сайте (чек-лист)

1. Настройка сервера `FARMHUB_SECRET`; проверка `Authorization: Bearer` на всех трёх точках (иначе 401).
2. Хранение шотов: поля из §2, статус «ждёт фермы» после кнопки «Отправить генерацию», плюс поля статуса из §5.
3. Форма шота: три слота картинок (персонаж / лицо / место), `line` по-русски, описания по-английски
   (или автоматический перевод перед отправкой), переключатель «черновик / финал».
4. `GET /api/farmhub/jobs/pending` — шоты «ждёт фермы» с картинками **ссылками**.
5. `POST /api/farmhub/jobs/{id}/status` — сохранить событие (с учётом `updated`), ответить 200.
6. `POST /api/farmhub/jobs/{id}/files` — сохранить файл (`draft` / `final`), лимит загрузки 200 МБ.
7. Интерфейс: статус и полоса по §5, плеер черновика после `job.stage`, плеер финала после `done`,
   «Исправить и отправить» после `job.rejected`, «Повторить» после `failed` (новый `id`).
8. Проверка: один шот с `"quality": "draft"` — через несколько минут должен прийти `kind=final` и `job.finished`.
   В Пульте (на ферме) вверху видно «сайт: на связи».
